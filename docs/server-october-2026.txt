---

As usual, a bunch of incidental changes had to be made to cope with about 10 years of version updates.  
in this process, using claude-ai as a copilot was hugely useful, bordering on indespensible.


OS Ubuntu

The main account for the site is "boardspace" whereas the old server used "boardspa".  There were
a disturbing number of places where the path "boardspa/" exists, they all had to be found and changed.
The main places were in cgi-bin/include.pl and include.csh, but also in cgi-bin/Debug.pm and 
server/static.conf .  

The old sever had a default apache configuration which was not exactly replicated.  The new 
root of the public html is ~boardspace/www/   

The new server environment doesn't permit direct sending email, so a proxy service
has to be used.  The current choice is smtp2go.com where the free level of service
is marginally adequate for boardspace (and real-me.net)


Perl

Lots of perl modules use obsolete $'varname which is replaced with $::varname. These show up
as warnings in /var/log/apache2/error.log, but some scripts leak those warnings into payloads,
so they all needed to be hunted down and replaced.   I systematically did perl <file> for all
the scripts to eliminate them.   

Some difference in path resolution caused "require 'xx'" to not resolve the same and miss tlib/
so a lot of "./" and "tlib/" had to be added (rather than messing with perl's defaults).  
Similarly for some package uses.  

I also added some links to assist using packages as they sat rather than removing them.

Mysl

A significant glitch showed up related to character sets.  Rather than alter the database
schema or modify all the scripts that use the database, I added this configuration to mysql
to force the old character set as a default.   I don't think there's any character set
related problem with the database, but in the future modifying the schema might avoid
latent problems.
future:/etc/mysql/mariadb.conf.d# diff 50-server.cnf 50-server.cnf~
# this is only for the mariadbd daemon
[mariadbd]
character-set-client-handshake = FALSE
character-set-server           = latin1
collation-server               = latin1_swedish_ci
init_connect                   = 'SET NAMES latin1'


PHP

Using a modern, maintainable php was the main motivation for this upgrade, but the main user, phpbb,
was written for a much older version of php.  We run a phpbb that was split from the main branch
many years ago, and boardspace version has a number of custom features to integrate it with the
boardspace database, and more recently to detect and trip-up rogue robots.  So my choice was to
upgrade the phpbb to the newer php version.  The main method here was to browse the BB and
use claude to say how to fix the problems.
