The Rules for Amazons


 
SET UP

Play on a 10x10 board, with starting position shown.
The mobile pieces are called amazons.

Each Turn:

Players alternate turns.

Move one amazon in a straight line (like a chess queen).   Amazons do not capture, so they must
stop before any occupied space.

Then, fire an arrow (also like a chess queen) to any reachable empty space.


Winning conditions:

If you cannot move any of your amazons, you lose the game.
